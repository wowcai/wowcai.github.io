## 冠军: France

- 四个模型都把 France 放在冠军位，这是本轮最强的团队级共识。
- France 的平均冠军 target posterior 约为 29.7%，平均四强 proxy 约为 79.4%。
- France 在当前 16 强 bracket 中不需要依赖旧小组赛模拟路径，候选集合只保留存活球队。
- Kylian Mbappe、Ousmane Dembele 和 Michael Olise 等前场信号同时进入多个个人奖项候选。
- Mike Maignan 的金手套共识从侧面支撑 France 的防守和深轮次路径。
- France 的进攻爆点、阵容深度和当前市场强度共同支撑冠军判断。
- 该队在冠军、四强纳入和多个奖项目标上同时领先，说明不是单一 target 的孤立结果。
- 主要风险来自 Argentina 的决赛路径，以及 Spain/Brazil 的半决赛级强度。
- 四个模型的 current-bracket sanity 都通过 10 个百分点阈值，France 的四强概率没有明显偏离市场锚。
- 因此 France 是本轮四模型综合下的明确冠军主选。

## 亚军: Argentina

- 四个模型都把 Argentina 放在亚军位，说明它是最稳定的决赛候选之一。
- Argentina 的平均 runner-up target posterior 约为 19.5%，平均四强 proxy 约为 63.7%。
- 当前路径为 Egypt 后接 Switzerland/Colombia 胜者，已经从 live bracket 重新起跑。
- Lionel Messi 仍在多个个人奖项目标中处于追赶区，支撑球队曝光和决赛舞台判断。
- Argentina 的比赛管理、前场关键回合能力和大赛经验支持长路径预测。
- 它没有超过 France，是因为冠军位和综合名次组合更集中在 France。
- Argentina 在四强纳入、亚军和第四名目标中都靠前，显示深轮次稳定性高。
- 若 France 路径受阻，Argentina 是最自然的上移候选。
- 该队的主要风险不是跌出强队池，而是与 France、Spain、Brazil 的名次重排。
- 因此 Argentina 是清晰的亚军主选，同时保留争冠上行风险。

## 第三名: Spain

- 四个模型都把 Spain 放在第三名位，确认 Spain 已重新进入 live-team 候选集合。
- Spain 的平均 third-place target posterior 约为 13.5%，平均四强 proxy 约为 47.4%。
- Portugal vs Spain 的 R16 对阵使用当前市场晋级概率，避免了旧 synthetic 偏差。
- Spain 的控球结构、中场质量和 Lamine Yamal 的年轻球员信号支撑深轮次路径。
- Spain 同时是最具观赏性球队的主要追赶者，说明风格和结果路径仍有联动。
- 它没有超过 France 和 Argentina，反映模型认为路径强但不是本轮最优冠军路径。
- Spain 的四强 proxy 在四个 run 中稳定接近半决赛层级。
- 若 B 区路径打开，Spain 仍有上移到决赛区间的空间。
- 主要风险来自 Portugal/Belgium 侧的同区竞争和 France/Argentina 的更高综合强度。
- 因此 Spain 是稳健第三名主选，而不是被旧版遗漏的边缘队。

## 第四名: Brazil

- 四个模型都把 Brazil 放在第四名位，第四个四强席位没有再出现分歧。
- Brazil 的平均 fourth-place target posterior 约为 9.9%，平均四强 proxy 约为 37.2%。
- Brazil 的路径为 Norway 后接 Mexico/England 胜者，当前模型没有让 Mexico 异常压过强队层。
- Vinicius Junior、Raphinha 和其他前场信号支撑 Brazil 的转换和进攻上限。
- Alisson、Marquinhos 等后场质量给 Brazil 的深轮次判断提供稳定底座。
- Brazil 的冠军和亚军强度低于前三队，因此更自然地落在第四名。
- 它仍明显处在四强候选池内，而不是仅靠单场爆冷路径进入名单。
- 主要追赶者是 England、Portugal、Mexico 和 Colombia 这一层。
- 如果 C/D 半区出现路径重排，Brazil 有向上或被 England 挤掉的风险。
- 因此 Brazil 是第四名主选，但确定性低于前三个席位。

## 金球奖: Lionel Messi (Argentina)

- 路径降权校准后，Lionel Messi (Argentina) 是金球奖主选。
- 原 target 首选是 Ousmane Dembele (France)，但该奖项受到球队路径和 expected matches 重复加权影响，本版采用路径降权后的主选。
- 该奖项的平均 target posterior 约为 2.1%，由于候选池很宽，绝对数值不能当作真实概率。
- Argentina 的亚军路径给该球员提供了足够赛事曝光，同时避免把冠军路径自动等同于金球。
- 该球员的创造、进攻参与和高光能力共同支撑综合个人奖项判断。
- Kylian Mbappe、Ousmane Dembele 和 Michael Olise 是主要风险候选，说明 France 路径仍有很强个人奖项竞争力。
- Lionel Messi 仍是外部追赶者，但 Argentina 亚军路径不足以推翻本轮首选。
- 金球不是纯射手奖，综合影响力和球队深度路径都被纳入。
- 主要风险候选：Ousmane Dembele (France), Kylian Mbappe (France), Michael Olise (France), Rayan Cherki (France)。

## 金靴奖: Harry Kane (England)

- 路径降权校准后，Harry Kane (England) 是金靴奖主选。
- 原 target 首选是 Kylian Mbappe (France)，但该奖项受到球队路径和 expected matches 重复加权影响，本版采用路径降权后的主选。
- 该奖项的平均 target posterior 约为 1.6%，但进球奖天然受小样本波动影响。
- England 的路径不如 France 但仍有足够样本；金靴校准更重视射手定位和进球率。
- Kane 的中锋定位、禁区触球和点球价值直接匹配金靴逻辑。
- Kylian Mbappe 和 Ousmane Dembele 是主要追赶者，体现 France 攻击线整体强度。
- Lionel Messi 仍有追赶信号，但金靴校准更偏稳定中锋得分样本。
- 该奖项对点球、单场爆发和淘汰赛对手质量非常敏感。
- 主要风险候选：Kylian Mbappe (France), Ousmane Dembele (France), Lionel Messi (Argentina), Michael Olise (France), DOUE Desire (France)。

## 金手套奖: Mike Maignan (France)

- 校准后，Mike Maignan (France) 仍是金手套奖主选。
- 该奖项的平均 target posterior 约为 3.3%。
- France 的冠军路径给门将奖提供了足够样本和叙事空间。
- Maignan 的门将质量和 France 的防守环境相互强化。
- Brice Samba 和 Robin Risser 的追赶位置显示 France 队内门将池在模型里整体受益于球队路径。
- Emiliano Martinez 是 Argentina 路径下的主要外部风险。
- 金手套依赖零封、关键扑救和淘汰赛叙事，仍有事件波动。
- 四模型全票说明当前球队路径和门将 profile 对齐。
- 主要风险候选：Brice Samba (France), RISSER Robin (France), Emiliano Martinez (Argentina), Geronimo Rulli (Argentina)。

## 最佳年轻球员: Lamine Yamal (Spain)

- 路径降权校准后，Lamine Yamal (Spain) 是最佳年轻球员主选。
- 原 target 首选是 DOUE Desire (France)，但该奖项受到球队路径和 expected matches 重复加权影响，本版采用路径降权后的主选。
- 该奖项的平均 target posterior 约为 5.5%。
- Spain 的深轮次路径给 Yamal 足够曝光，且个人年龄/能力信号更强。
- 年龄资格、当前角色、创造力和潜力信号共同支撑该奖项。
- Doue 是原 target 首选和最明确追赶者，但主要优势来自 France 路径。
- Warren Zaire-Emery、Robin Risser 和 Pau Cubarsi 说明年轻候选池仍有深度。
- 该奖项比金靴、最佳进球更少依赖单次事件。
- 主要风险候选：DOUE Desire (France), ZAIRE-EMERY Warren (France), RISSER Robin (France), PAZ Nico (Argentina)。

## 决赛最佳球员: Kylian Mbappe (France)

- 校准后，Kylian Mbappe (France) 仍是决赛最佳球员主选。
- 该奖项的平均 target posterior 约为 2.4%。
- France 冠军主线是该判断的直接前提。
- Mbappe 的单场决定能力适合决赛最佳这种高杠杆目标。
- Ousmane Dembele 和 Michael Olise 是同队清晰追赶者。
- 该奖项没有强制绑定冠军队外的候选，但当前冠军路径使 France 球员集中领先。
- 决赛最佳高度依赖单场进球、助攻和关键回合。
- 四模型全票说明主线剧本非常一致。
- 主要风险候选：Ousmane Dembele (France), Michael Olise (France), DOUE Desire (France), Rayan Cherki (France)。

## 最佳进球: Lionel Messi (Argentina)

- 路径降权校准后，Lionel Messi (Argentina) 是最佳进球主选。
- 原 target 首选是 Kylian Mbappe (France)，但该奖项受到球队路径和 expected matches 重复加权影响，本版采用路径降权后的主选。
- 该奖项的平均 target posterior 约为 1.4%，绝对值较低是因为候选池极宽。
- Messi 的任意球、远射、创造和单次技术高光更匹配最佳进球校准画像。
- Argentina 的深轮次路径增加 Messi 产生候选进球的曝光。
- Kylian Mbappe 和 Ousmane Dembele 是主要追赶者，说明 France 技术高光风险仍然很强。
- 最佳进球是最事件驱动的奖项，不能过度解读微小 posterior 差距。
- 如果 France 或 Spain 产生单次高难度进球，该奖项容易改写。
- 主要风险候选：Kylian Mbappe (France), Ousmane Dembele (France), DOUE Desire (France), Michael Olise (France)。

## 公平竞赛球队: Paraguay

- 校准后，Paraguay 仍是公平竞赛球队主选。
- 该目标的平均 target posterior 约为 7.6%，但前三名差距很小。
- Paraguay、Switzerland 和 Egypt 的排序非常接近，说明该奖项确定性低。
- 公平竞赛与冠军路径没有强绑定，非四强队伍领先是合理结果。
- 该目标主要依赖纪律代理、犯规风险和比赛情境。
- Spain 仍在追赶区，说明控球型强队也有公平竞赛路径。
- 四模型全票给主选稳定排序，但不消除小差距风险。
- 如果实际淘汰赛出现红黄牌或加时混乱，排序会非常敏感。
- 主要风险候选：Switzerland, Egypt, Spain, Morocco。

## 最具观赏性球队: Spain

- 路径降权校准后，Spain 是最具观赏性球队主选。
- 原 target 首选是 France，但该奖项受到球队路径和 expected matches 重复加权影响，本版采用路径降权后的主选。
- 该目标的平均 target posterior 约为 12.3%，处在第一梯队但不是原始 target 第一。
- Spain 的控球结构、中场连接和 Yamal 边路创造共同支撑观赏性校准判断。
- France 是最主要追赶者，靠冠军路径、前场球星和进攻爆点保持竞争。
- Argentina 与 Brazil 也有高光球员，但平均强度落后。
- 该奖项与 Spain 的控球风格和最佳年轻球员主线互相强化。
- 若 France 夺冠且攻击线持续打出高比分，存在反超风险。
- 主要风险候选：France, Argentina, Brazil, England。
