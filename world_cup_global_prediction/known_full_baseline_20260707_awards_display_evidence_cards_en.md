## Data And Method Notes

- This report uses the four current-bracket target-level forecasts and no longer uses old group-stage-start simulation as the main conclusion.
- This version locks France 1-0 Paraguay, Morocco 3-0 Canada, Norway 2-1 Brazil, and England 3-2 Mexico.
- Brazil, Mexico, Canada, and Paraguay are removed from the current tournament, target forecasts, and award candidate pools.
- DeepSeek V4 Pro, OpenAI GPT-5.5, and Claude Sonnet 4 are the current 90-product main packages; DeepSeek Chat is the 88-product comparison package.
- All four packages have zero import errors; the three 90-product main packages retain only 001, 002, and 019 as synthetic matches.
- Unplayed R16 matches use current to-advance odds, QF uses conditional semifinal-market probabilities, and SF/Final use a market-strength and adjusted-rating blend.
- All four current tournaments pass raw and no-vig market sanity checks, with maximum raw delta around 5.1-5.2 percentage points.
- Target-level posterior values are relative candidate-pool strengths, not direct real-world probabilities.
- Team placements use the raw current-bracket target output; individual and style awards use path-deweighted calibration to avoid repeating France's champion path across every award.
- Once Portugal-Spain, USA-Belgium, Argentina-Egypt, and Switzerland-Colombia have actual results, those results should be locked and the forecast rerun.
